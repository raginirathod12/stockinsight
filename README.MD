# 📈 StockInsight

**Your Gateway to Stock Market Knowledge**

StockInsight is a web-based platform designed to bring stock market-related articles and financial information together in one place. It aims to help users explore market-related content, discover relevant articles, and engage with financial topics through an interactive and user-friendly interface.

## ✨ Features

- 📰 **Stock Market Articles** — Explore articles focused on stocks and financial markets.
- 🔍 **AI-Powered Article Search** — Find relevant articles using a simple search assistant.
- ❤️ **Like Articles** — Interact with articles you find useful.
- 💬 **Comments** — Share your thoughts and engage in discussions.
- 🔗 **Share Articles** — Share interesting articles with others.
- 🔐 **User Authentication** — Register and log in to your account.
- 📱 **Responsive Design** — Designed with usability across different screen sizes in mind.

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling and layout
- **JavaScript** — Interactive functionality
- **Firebase Authentication** — User registration and login
- **Cloud Firestore** — Database for articles and user interactions, if enabled in the implementation
- **Firebase Hosting** — Deployment option

## 🚀 Getting Started

### Prerequisites

- A modern web browser
- [Visual Studio Code](https://code.visualstudio.com/)
- The Live Server extension for VS Code
- A Firebase project

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/raginirathod12/stockinsight.git
   ```

2. Open the project folder in Visual Studio Code.

3. Configure your Firebase project in `firebase-config.js` using the configuration provided in your Firebase Console.

4. Enable **Email/Password** authentication in Firebase Authentication if your login system uses it.

5. Install the Live Server extension in VS Code.

6. Right-click `index.html` and select **Open with Live Server**.

7. Open the website in your browser and explore the available features.
